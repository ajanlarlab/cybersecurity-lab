## About This Project | Proje Hakkında

### English

This repository documents my hands-on cybersecurity learning journey, focusing on Blue Team defense, Red Team security testing, SOC analysis, Python automation, Linux security, and ethical penetration testing.

My goal is to develop practical cybersecurity skills, build security tools, analyze threats, and create a professional portfolio.
